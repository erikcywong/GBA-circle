Section 05 / Risk & Compliance

风险与合规

三份文档在合规上只写了一行提醒。本节把风险拆成 12 项并给出概率×影响分布， 然后把最容易被忽略的两件事算清楚：跨境付汇的代扣代缴成本，和数据出境的判定边界。

3 项极高影响风险 跨境付汇税负 ≈ 佣金的 11–16% 数据出境：判定边界清楚，管控得住

一、风险矩阵：概率 × 影响

右上角（高概率 + 高影响）是必须在前 90 天解决的事项，不是"以后再说"。

气泡大小表示"可控难度"——越大越难通过自身努力降低。

三、资金路径：三种模式，两种违法

模式 A · 禁止 —— 资金过手渠道

客户在旅行社门店付款
→
旅行社账户收团费（无支付牌照）
→
旅行社转账给园区（扣佣金后）

两个问题：① 旅行社无牌照从事资金归集与转付，可能构成无证支付结算（"二清"）；② 园区承担旅行社破产、挪用、跑路的全部风险。L2 文档明确指出这一点，判断完全正确，必须坚持。

模式 B · 推荐（内地主体渠道）—— 统一收款 + 持牌分账

客户扫码付款进园区商户号
→
系统归因识别渠道 / 团 / 巴士
→
持牌分账T+1 / T+7 自动分账给渠道子商户

模式 C · 港澳渠道的必然形态 —— 统一收款 + 月结 + 跨境付汇

客户扫码付款进园区商户号（收单需持牌机构支持港澳钱包）
→
系统归因 + 出结算单（月结，最低 HK$1,000 起结）
→
跨境付汇：税务备案 → 代扣代缴 → 汇款至港澳账户
◆ 为什么"持牌分账"解决不了港澳渠道的问题

分账系统的分账接收方必须是该收单机构体系内的子商户，而成为子商户通常要求持有内地营业执照与结算账户。 绝大多数香港、澳门的中小旅行社没有内地主体。因此对港澳渠道而言，落地的现实路径就是月结 + 跨境付汇—— 这条路径的成本与合规要求，恰恰是原文完全没有提及的。

四、被漏掉的一笔账：跨境付汇的税务成本

向港澳旅行社支付佣金 = 向境外支付服务费。这是要缴税的，而且不小。

项目金额 / 税率说明
假设：月度佣金总额HK$300,000≈ ¥276,000
代扣增值税6%≈ ¥16,560
预提企业所得税（无税收协定）10%≈ ¥27,600
预提企业所得税（适用内地—香港安排，5%）5%≈ ¥13,800，需符合"受益所有人"条件
合计税负（区间）¥30,360 – ¥44,160约占佣金总额的 11% – 16%
等效佣金率抬升+2 ~ 3 pp18% 的名义佣金 ≈ 20–21% 的实际成本
对外支付税务备案门槛单笔 ≥ US$50,000需先备案后付汇
◆ 这条账改变了一个结论

在 盈利模式 中，我们把佣金从 20% 压到 15–18% 定为关键动作。 现在看：名义佣金 18% + 跨境税负 11–16% ≈ 实际成本 20–21%。 也就是说，跨境付汇的税负几乎把"降佣金"的努力全部吃掉。

这带来两条更硬的建议：

  • 把港澳渠道名义佣金压到 15%，为税负留出空间，使实际成本仍控制在 17% 以内；
  • 或改变激励结构——用实物激励（免费房券、鱼宴券、员工旅游名额）替代一部分现金佣金。实物不产生跨境付汇，也不产生预提所得税，且能引导渠道员工亲自到园体验产品。
◆ 还需核实的三项

① 港澳旅行社是否需要在内地办理税务登记或提供税务信息；② 澳门方适用的是内地—澳门税收安排还是其他安排；③ 佣金是否可被认定为"境内劳务"从而适用不同处理。建议由本地税务师出具书面意见。

五、数据合规：边界清楚，管控得住

✓合规的那一半（数据不出境）

数据在内地采集、内地存储、内地处理，不构成数据出境。以下功能全部安全：

  • 扫码归因、客户绑定、渠道归因
  • 团码核销、巴士扫码、到站打卡
  • 佣金计算、结算单生成
  • 园区后台的数据画像与看板

依据：PIPL 第 38–39 条关于出境的判定，核心是"是否向境外提供"。

!需要管控的那一半

以下动作一旦实施，即构成从内地向港澳提供个人信息（数据出境）：

  • 港澳门店端登录系统查看本团客户姓名 / 联系方式 / 年龄段明细
  • 向港澳渠道推送客户名单用于提前联络
  • 园区把客户画像数据同步给境外营销服务商

缓解方案（L3 文档已无意中解决）：渠道端只显示聚合数据——本团人数、已付/待付金额、状态、核销进度；不显示任何个人明细。这既满足了渠道的对账需求，又避免了数据出境评估。建议将此固化为《渠道数据可见性规范》并写入合同附件。

三地法规的交叉要求

法域法规对本案的核心要求
内地PIPL（个人信息保护法）首次扫码明示同意；最小必要；营销需单独同意且可撤回；出境需标准合同备案或安全评估；境内存储
中国香港PDPO（个人资料（私隐）条例）收集目的与用途须告知；数据使用限于原目的；查询与更正权
中国澳门《个人资料保护法》需明确同意；敏感数据处理更严格；跨境转移需符合法定条件
实操建议：同意书做分层设计——"必要同意"（用于核销与履约）与"营销同意"（用于推送与画像）分开；未勾选营销同意不影响入园，避免因强制同意导致的渠道抵触与合规瑕疵。

六、证照与许可清单

前置与土地

  • 建设用地 / 集体经营性建设用地入市 或 点状供地批复（决定项目能否存在）
  • 营业执照（经营范围须覆盖餐饮、住宿、养殖、洗浴、旅游服务）
  • 项目环评（餐饮 + 养殖 + 锅炉，视规模）
  • 水土保持方案（若涉及水面开挖）

餐饮与食品

  • 食品经营许可证（含冷食类类别视菜单而定）
  • 从业人员健康证明（全员）
  • 食品留样与进货台账制度
  • 明厨亮灶（建议，非强制但提升信任）

养殖与水产

  • 水域滩涂养殖证（自养活鱼前置）
  • 水产苗种生产许可证（若自繁苗种）
  • 动物防疫条件合格证（活鱼运输环节）
  • 养殖尾水处理方案与排水许可
  • 垂钓/捕捞相关许可（视水域性质）

水疗与住宿

  • 公共场所卫生许可证（水疗、泳池、洗浴）
  • 特种行业许可证（住宿，公安备案）
  • 消防验收 / 备案合格
  • 锅炉与压力容器使用登记（热水系统）
  • 水质检测报告（按周期更新）

交通与旅游

  • 道路运输经营许可证（自营接驳前置）
  • 旅行社业务经营许可证 或 与持牌社合作（承接"直营团"前置）
  • 跨境旅游大巴：两地牌与配额（合作方资质核验）
  • 营业性演出许可证（民族表演）

支付、广告与其他

  • 持牌支付机构合作协议（收单 / 分账，禁止自建资金池）
  • 对外支付税务备案（跨境佣金付汇）
  • 户外广告设置许可（口岸 / 巴士车身）
  • 广告法合规审查（绝对化用语与专利公示）
  • 公众责任险 / 食品安全责任险 / 游客意外险 / 水上活动责任险

七、风险治理机制建议

1三份书面法律意见

开工前委托本地专业机构分别出具：土地用途意见书、旅游与客运资质路径方案、数据合规与出境评估意见。三份文件是投资人尽调的第一道门槛，没有它们，融资基本无从谈起。

2合规日历

把卫生许可复检、水质检测、消防年检、健康证换发、保险续保、税务备案续期全部录入系统日历并设置提前 30 天提醒。合规事故几乎都源于"忘了续期"。

3舆情预案

为"佣金规则""风控机制""食品安全"三类话题各准备一份对外统一话术。特别是风控话术必须统一为："系统按合同和资源紧张度自动要求预付锁位"——永远不提"评分""风险等级""黑名单"。

◆ 本节结论

合规不是成本，是准入牌照。这 12 项风险里，R1（土地）、R2（旅行社资质）、R3（跨境税务）、R4（二清）四项只要有一项没解决，前面所有的商业模式设计、单位经济测算、系统开发投入都是沉没成本。 建议把"合规四项确认"设为项目的 G0 门禁：未通过，不投一分钱工程款。
